# Contributing

Contributions and reproducible bug reports are welcome.

1. Fork the repository and create a focused branch.
2. Keep the userscript dependency-free and preserve the minimal permission set.
3. Run `npm test`.
4. Test against at least one public Card2Brain box with more than one visible page.
5. Open a pull request describing the reported, detected, and exported card counts.

Never commit Card2Brain session data, cookies, private flashcards, exported study data, or credentials.
